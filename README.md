# FolioForge

**Build visually. Learn the code.** A Windows app for students who are
learning HTML, CSS and JavaScript. Build a portfolio, a landing page or a
small-business website from blocks, see the real code behind it, and export a
website that works offline.

Developed by Ian Magistrado Naz.

## Download

Get **FolioForge-Setup-x.y.z.exe** from the
[latest release](https://github.com/iannaz1228/folioforge-releases/releases/latest)
and run it.

- Works on 64-bit Windows 10 (version 1809 or later) and Windows 11.
- Installs for the current user, without administrator rights.
- The setup isn't code-signed yet, so the first time Windows may show
  "Windows protected your PC". Click **More info**, then **Run anyway**.

## Updates

In versions after 1.0.0, use **Check for updates** in the ☰ menu or at the
bottom of the Home screen. FolioForge downloads the new version, checks it,
and restarts with the update installed. FolioForge 1.0.0 can't check for
updates yet: download the new setup from this page and run it.

This repository only holds the installers and release notes.
